# 鋳造型ノウハウ集

鋳造の型（砂型・中子・金型・ダイカスト金型）に関する現場のノウハウを蓄積・検索するための Web アプリです。
サーバー不要で、ブラウザの localStorage にデータを保存します。

## 機能

- **ノウハウの登録・編集・削除**
  「現象・課題」「原因」「対策・ノウハウ」「備考」の 4 項目で構造化して記録
- **カテゴリ分類**
  砂型 / 中子 / 金型（重力・低圧） / ダイカスト金型 / 方案設計 / 鋳造欠陥 / 塗型・離型剤 / 型の保守・寿命 / 安全
- **タグ付けとタグ絞り込み**（複数タグの AND 検索）
- **全文検索**（全角・半角、大文字・小文字を区別しない。空白区切りで複数語の AND 検索）
- **画像の添付**（写真・スケッチ・図を 1 件あたり最大 20 枚。ファイル選択、ドラッグ＆ドロップ、貼り付けに対応。長辺 1600px に自動縮小）
- **お気に入り**
- **JSON エクスポート／インポート**（バックアップや他の端末との共有に）
- **初期データ**として 18 件のノウハウを収録（生型砂の水分管理、押湯設計、湯口比、ダイカストの焼付き・ヒートチェック、水蒸気爆発の防止など）
- スマートフォン対応のレスポンシブレイアウト

> 初期データの数値は一般的な目安です。実際の設備・材質・製品形状に合わせて現場で検証・調整してください。

## 使い方

```bash
npm install
npm run dev        # 開発サーバー（http://localhost:5173）
npm test           # ユニットテスト
npm run build      # dist/ に本番ビルドを出力
npm run preview    # ビルド結果をローカルで確認
```

`dist/` は静的ファイルのみなので、社内の Web サーバーや GitHub Pages にそのまま配置できます。
GitHub Pages を使う場合は、リポジトリ設定の Pages > Source を「GitHub Actions」にすると、`main` ブランチへの push で自動配信されます（`.github/workflows/deploy-pages.yml`）。

## データについて

- 文章データはブラウザごとの localStorage（キー `casting-mold-knowhow:v1`）、画像本体は IndexedDB（データベース名 `casting-mold-knowhow`）に保存されます。
  ブラウザのデータを消すと失われるため、定期的に「JSON エクスポート」でバックアップしてください。エクスポートには画像も含まれます。
- インポートは既存データに統合されます。同じ ID のノウハウは上書き、それ以外は追加されます。
- 「初期データに戻す」は登録したノウハウをすべて消去します。

## 技術スタック

- React 19 + TypeScript + Vite
- テスト: Vitest

## ディレクトリ構成

```
src/
  App.tsx            画面全体の状態管理
  types.ts           データ型とカテゴリ定義
  store.ts           保存・読込・CRUD・インポート／エクスポート
  imageStore.ts      画像本体の保存（IndexedDB）と縮小処理
  search.ts          検索・絞り込み・集計
  data/seed.ts       初期ノウハウデータ
  components/        UI コンポーネント
  __tests__/         ユニットテスト
```
